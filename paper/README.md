# Paper Directory

This directory contains manuscript materials for the academic paper.

## Structure

### `drafts/`
Paper drafts and revisions.
- Version-controlled drafts (v1, v2, etc.)
- Quarto/LaTeX source files
- Submission-ready manuscripts

### `figures/`
Publication-ready figures.
- High-resolution PNG/PDF formats
- Consistent styling per journal requirements
- Named according to paper figure numbers (fig1_concentration.png, etc.)

### `tables/`
Publication-ready tables.
- LaTeX or Word-compatible formats
- Formatted per journal style guide
- Named according to paper table numbers

## Target Journals

1. **Journal of Central Banking** - Focus on monetary policy communication
2. **European Journal of Political Economy** - Political economy of Euro adoption
3. **Financial Theory and Practice** - Croatian financial economics

## Paper Outline

1. Introduction
2. Literature Review (Attention Economics, Central Bank Communication)
3. Institutional Context (HNB, Euro Adoption)
4. Data and Methods
5. Results
   - H1: Attention Distribution
   - H2: Institutional Gap
   - H3: Sentiment Effects
   - H4: Event-Driven Attention
   - H5: Euro Structural Break
6. Discussion
7. Conclusion
